# 分類標籤

skill 以五個標準分類角色來描述 issue 狀態。本檔案把這些角色對應到本 repo issue tracker 實際使用的標籤字串。

| mattpocock/skills 標籤 | 本 repo 標籤        | 意義                            |
| ---------------------- | ------------------- | ------------------------------- |
| `needs-triage`         | `needs-triage`      | 需由維護者評估                  |
| `needs-info`           | `needs-info`        | 等待回報者補充資訊              |
| `ready-for-agent`      | `ready-for-agent`   | 規格完整，可交給 AFK agent 執行 |
| `ready-for-human`      | `ready-for-human`   | 需要人工實作                    |
| `wontfix`              | `wontfix`           | 不會處理                        |

skill 提到某個角色時（例如「套用可交給 AFK agent 的標籤」），請使用表格中對應的標籤字串。

如需改用其他名稱，修改右側欄位即可。
