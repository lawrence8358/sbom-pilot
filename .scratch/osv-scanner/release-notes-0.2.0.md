## SBOM Pilot v0.2.0

### 新增

- 所有開發模式預設啟用 OSV 弱點掃描，設定放在 DT 勾選框上方。
- 支援官方最新穩定版本或指定版本，下載驗證 SHA-256 並重用相同 Agent 的版本快取。
- Markdown 報告列出風險分級、CVSS、CVE 與修復版本，依嚴重程度排序。
- 報告與 SBOM 同時發佈成品，並附到 CI 執行結果的 Extensions 摘要，可直接查看。

### 改善

- 預設 SBOM 檔名改為 sbom.cdx.json，保留自訂名稱功能。
- 發現弱點只警告；技術錯誤會回報失敗，仍嘗試保留有效 SBOM，彙整 OSV、DT、成品與摘要錯誤。
- 專案版本與相關文件同步更新至 0.2.0。

### 驗證

- 136 項單元測試通過。
- 建置、正式 VSIX 封裝與來源完整性校驗通過。
- Windows／Linux 真實 OSV 掃描、風險／CVE 報告與版本快取驗證通過。
- Node20／24 的 dist／VSIX 入口驗證通過；本機解包 Task 驗證成品及摘要命令。
- 真實 Azure 的新版安裝、摘要呈現與非同步上傳仍待驗證；市集套件由使用者手動上傳。
