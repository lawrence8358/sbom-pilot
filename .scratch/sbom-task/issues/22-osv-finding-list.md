# 22: OSV 結果帶出逐筆弱點與風險等級（先重構）

Type: task
Status: ready-for-agent
Blocked by: 21

## 規格

[OSV 失敗門檻 spec](../../osv-fail-threshold/spec.md)。本張是後續門檻判定與 issue 輸出的先重構，Task 對外行為不變。

## 要建立的行為

OSV 掃描結果除了既有的報告路徑、版本、是否有弱點，另外帶出逐筆弱點清單：風險等級（危急／高／中／低／無／未知）、套件名稱、版本、生態系、OSV ID、CVE、修復版本。清單與 OSV 弱點報告來自同一次 JSON 解析，排序一致（依風險由高至低），讓後續門檻判定、issue 與報告不會互相矛盾。

## 驗收

- [ ] OSV 結果包含逐筆弱點清單，欄位如上；沒有弱點時為空清單。
- [ ] 等級界線沿用現有報告分級：危急 ≥9.0、高 ≥7.0、中 ≥4.0、低 >0、無 =0、缺少評分為未知。
- [ ] 清單筆數、順序、等級與 Markdown 報告的列一致（以 OSV JSON fixture 驗證，含 CVSS 0 與缺少評分）。
- [ ] Markdown 報告內容、成品、摘要、log 與 Task 結果完全不變；既有測試全數通過。
