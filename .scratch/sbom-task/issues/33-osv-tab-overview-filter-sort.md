Type: task
Status: resolved
Blocked by: 35

## 規格

[完整 SBOM 規格](../../full-sbom/spec.md)，使用者故事 19、22、29–30、34。

## 要建立的行為

「OSV 弱點報告」頁籤補上總覽表（產品／開發套件額外／完整合計三列的受影響套件、弱點數與各等級數量）、依等級篩選、欄位排序，以及各種空狀態，讓使用者能快速掌握規模並只看關心的弱點。

## 驗收

- [x] 總覽表三列，各等級數量為 0 時以淡色顯示。
- [x] 等級篩選可多選切換，並有「全部顯示」；區塊標題顯示「顯示 N ／ M 筆」。
- [x] 可依等級、CVSS、套件、發佈日期、最後修改排序；預設 CVSS 由高至低；排序狀態以 `aria-sort` 呈現，按鈕可用鍵盤操作。
- [x] 兩個區塊固定出現；無弱點時分別顯示「產品 SBOM 未發現已知弱點。」「開發套件無額外弱點。」；篩選後無資料時顯示「目前篩選條件下沒有弱點。」
- [x] 區塊狀態為 disabled 時頁籤顯示「本次未執行 OSV 弱點掃描」、failed 時顯示「OSV 弱點掃描失敗，詳見建置日誌」；Task 端在未啟用 OSV 時上傳 disabled 附件由 32 負責。
- [x] `schemaVersion` 無法辨識或附件缺失時顯示明確錯誤訊息，不顯示空表格。
- [x] DOM 測試以契約 fixture 涵蓋總覽統計、篩選、排序與所有空狀態。
